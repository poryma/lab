# Life, Death & Inequality Lab — website

Static site for Jaein Lee's lab at Korea University Sejong. Plain HTML + CSS, no build step. Served by GitHub Pages.

- `index.html` — home, research, publications, teaching, join
- `ai.html` — AI principles and graduate student guidelines
- `style.css` — shared styles

To update: edit the HTML, commit, push. GitHub Pages republishes in about a minute.
